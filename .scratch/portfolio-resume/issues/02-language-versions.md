# 02: Русская и английская языковые версии

**What to build:** Посетитель получает русскую или английскую главную по явному адресу, а на корневой странице — язык браузера. Переключатель в шапке доступен на любом экране и соблюдает отдельное правило неизменного адреса для корневой страницы.

**Blocked by:** 01 — Русская главная по референсу.

**Status:** ready-for-human

- [x] Русская и английская главные открываются по постоянным адресам с явными языковыми префиксами, включая прямой вход и перезагрузку. Язык браузера не переопределяет явный адрес.
- [x] Переведены интерфейс, содержимое главной, подписи контактов и управления, заголовок и описание страницы. Перевод сохраняет реальные факты автора.
- [x] Исходный статический HTML корневой страницы русский. После подключения приложения основной русский язык браузера, включая региональные варианты, выбирает RU; английский и неподдерживаемые языки выбирают EN. Содержимое не скрывается до определения языка, начальное подключение не конфликтует со статическим HTML.
- [x] На корневой странице ручной выбор меняет содержимое, язык документа и метаданные, сохраняя URL и не вызывая перенаправление. Обычное обновление состояния не отменяет ручной выбор; постоянная память между посещениями не вводится.
- [x] На явных языковых страницах переключатель ведёт на соответствующую страницу другого языка. Общий механизм построения адресов пригоден для последующих каталога и страниц проектов.
- [x] Переключатель доступен с клавиатуры и на мобильном экране, текущий язык понятен визуально и вспомогательным технологиям. Общая оболочка оформлена Tailwind CSS.
- [x] Обе версии дают существующий русский PDF с понятной подписью языка. Назначение PDF задаётся независимо по языкам: замена английского не требует изменения русской ссылки или разметки.
- [x] Неизвестный языковой префикс возвращает HTTP 404. Корневая и обе языковые главные содержат готовый HTML; корневая не получает запрета индексации.
- [ ] Проверки браузером и HTTP охватывают RU, EN, неподдерживаемый и региональный русский язык, приоритет URL, переключатель, неизменный корневой адрес, доступность PDF и прямые входы.

## Scope notes

Соблюдать ADR о языковых адресах. Полные canonical, языковые альтернативы и sitemap завершает 05. Этот тикет не создаёт новый английский PDF и не меняет факты опыта.

## Comments

22.10.2026: реализованы общая главная для /, /ru/ и /en/, переводы содержимого и интерфейса, язык документа и метаданные, переключатель с отдельным поведением на корневой странице, общий построитель языковых адресов и независимые назначения PDF. Факты опыта и дата NDA сохранены. README не изменён; коммит не создавался по указанию владельца.

Проверки: TypeScript, ESLint, статическая сборка. HTTP по готовой сборке через временный локальный файловый сервер: три главные возвращают 200 с нужным HTML, языком и метаданными, без noindex; /fr/, /de/ и /ru/missing/ возвращают 404; PDF возвращает 200 и имеет сигнатуру PDF. Правила production-хостинга остаются в пункте 06.

Браузером проверены прямые входы и перезагрузка явных адресов, переход EN → RU и обратно клавиатурой, текущий язык в aria-current/aria-pressed, переключение на / без изменения URL, изменение метаданных, сохранение выбора при раскрытии опыта, сброс после перезагрузки и отсутствие сообщений об ошибках гидратации. На ширине 320 px обе версии не имеют горизонтальной прокрутки, навигация и переключатель доступны. Оба независимых ревью (Standards и Spec) прошли без замечаний.

Последний критерий оставлен для ручной приёмки: доступный браузер не предоставляет управление языковым профилем, поэтому полная матрица RU, EN, неподдерживаемого и регионального русского языка и оба направления приоритета URL не подтверждены браузером. Автоматические тестовые файлы и Playwright не добавлялись согласно ранее зафиксированному решению владельца.

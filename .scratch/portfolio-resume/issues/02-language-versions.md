# 02: Русская и английская языковые версии

**What to build:** Посетитель получает русскую или английскую главную по явному адресу, а на корневой странице — язык браузера. Переключатель в шапке доступен на любом экране и соблюдает отдельное правило неизменного адреса для корневой страницы.

**Blocked by:** 01 — Русская главная по референсу.

**Status:** ready-for-agent

- [ ] Русская и английская главные открываются по постоянным адресам с явными языковыми префиксами, включая прямой вход и перезагрузку. Язык браузера не переопределяет явный адрес.
- [ ] Переведены интерфейс, содержимое главной, подписи контактов и управления, заголовок и описание страницы. Перевод сохраняет реальные факты автора.
- [ ] Исходный статический HTML корневой страницы русский. После подключения приложения основной русский язык браузера, включая региональные варианты, выбирает RU; английский и неподдерживаемые языки выбирают EN. Содержимое не скрывается до определения языка, начальное подключение не конфликтует со статическим HTML.
- [ ] На корневой странице ручной выбор меняет содержимое, язык документа и метаданные, сохраняя URL и не вызывая перенаправление. Обычное обновление состояния не отменяет ручной выбор; постоянная память между посещениями не вводится.
- [ ] На явных языковых страницах переключатель ведёт на соответствующую страницу другого языка. Общий механизм построения адресов пригоден для последующих каталога и страниц проектов.
- [ ] Переключатель доступен с клавиатуры и на мобильном экране, текущий язык понятен визуально и вспомогательным технологиям. Общая оболочка оформлена Tailwind CSS.
- [ ] Обе версии дают существующий русский PDF с понятной подписью языка. Назначение PDF задаётся независимо по языкам: замена английского не требует изменения русской ссылки или разметки.
- [ ] Неизвестный языковой префикс возвращает HTTP 404. Корневая и обе языковые главные содержат готовый HTML; корневая не получает запрета индексации.
- [ ] Проверки браузером и HTTP охватывают RU, EN, неподдерживаемый и региональный русский язык, приоритет URL, переключатель, неизменный корневой адрес, доступность PDF и прямые входы.

## Scope notes

Соблюдать ADR о языковых адресах. Полные canonical, языковые альтернативы и sitemap завершает 05. Этот тикет не создаёт новый английский PDF и не меняет факты опыта.

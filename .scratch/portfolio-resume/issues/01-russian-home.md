# 01: Русская главная по референсу

**What to build:** Работодатель открывает готовую русскую главную, знакомится с автором и его реальным опытом, получает PDF-резюме и может связаться с ним. Страница сохраняет характер референса и плавное движение кита, работает на телефоне и доступна в сгенерированном HTML.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Создан воспроизводимо запускаемый проект на Vue 3, Nuxt, строгом TypeScript, Tailwind CSS и pnpm с зафиксированными зависимостями и командой статической сборки.
- [ ] Главная представляет автора, специализацию, местоположение и удалённую работу, реальный опыт, навыки и подход, образование, интересы и контакты из референса. Не добавлены неподтверждённые факты; дата текущей работы под NDA не исправлена по догадке.
- [ ] Посетитель раскрывает результаты и полный стек опыта. Существующие назначения Telegram, GitHub и email сохранены, русский PDF доступен по рабочей ссылке.
- [ ] Данные профиля, опыта и назначения PDF хранятся отдельно от отображения в JSON или типизированных константах; статические материалы включены в результат сборки. Работа сайта не требует исходной папки референса на сервере или базы данных.
- [ ] Основное оформление выполнено через Tailwind CSS: тёмная палитра, звёзды, типографика, состояния элементов и адаптивность согласованы с референсом. Дополнительный CSS допускается для движения кита и декоративных эффектов.
- [ ] Кит плавно покачивается и движется по вертикали без сдвига компоновки. При уменьшении движения декоративная анимация отключается или существенно уменьшается.
- [ ] На узком и широком экране доступны контакты, навигация и PDF; нет горизонтальной прокрутки. Есть семантические заголовки, клавиатурное управление и видимый фокус.
- [ ] Основное содержимое и ссылки доступны в исходном HTML без JavaScript. Несуществующий адрес даёт понятную страницу ошибки и HTTP 404 при обслуживании статической сборки.
- [ ] Добавлены проверки наблюдаемого поведения главной через HTTP и браузер и инструкция локального запуска. Реализация внутренних функций или имена CSS-классов не закреплены тестами.

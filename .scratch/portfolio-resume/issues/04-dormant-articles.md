# 04: Заготовки выключенного раздела статей

**What to build:** Владелец получает готовые русские и английские заготовки списка статей и отдельной статьи, включаемые одной настройкой сборки. В обычной первой версии посетитель нигде не видит этот раздел и не может открыть его по прямому адресу.

**Blocked by:** 02 — Русская и английская языковые версии.

**Status:** ready-for-agent

- [x] Подготовлены локализованные каталог и подробная страница как минимум одной статьи с явно тестовым названием, описанием, датой и основным содержимым.
- [x] Раздел подключается одним объектом маршрута с дочерними страницами в app/router.options.ts, первоначально он закомментирован. Нет необходимости раскомментировать фрагменты нескольких модулей; изменение применяется пересборкой (уточнение владельца от 28.10.2026).
- [x] При выключении на корневой, обеих языковых главных и общих областях сайта отсутствуют пункты меню, блоки, карточки и ссылки статей.
- [x] Выключенные страницы не регистрируются как доступные маршруты и не публикуются статической сборкой. Прямые обращения к списку и отдельной статье в обеих языковых версиях возвращают HTTP 404.
- [x] Источник модели публикуемых страниц учитывает выключение, чтобы последующая генерация sitemap не добавляла статьи по наличию записей в контенте.
- [x] В сборке с включённым разделом работают каталог, переход к статье, прямое открытие, возврат и переключение языка на той же статье. Страницы содержат готовый локализованный HTML и основные метаданные.
- [x] Заготовки используют Tailwind CSS и общую тему, доступны на телефоне и с клавиатуры. Контент хранится отдельно от отображения и легко заменяется.
- [x] Проверки через HTTP и браузер охватывают выключенную сборку и отдельную включённую сборку; окончательное обычное значение настройки остаётся выключенным.

## Scope notes

Публичный запуск статей в первой версии не требуется. Проверка общей навигации на страницах проектов дополнительно входит в 05, который зависит и от проектов, и от этого раздела. Сложная редакционная система и поиск по статьям не нужны.

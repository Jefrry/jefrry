# 03: Каталог и страницы проектов портфолио

**What to build:** Посетитель просматривает два тестовых проекта, фильтрует каталог, открывает подробности и переключает язык, оставаясь на том же проекте. Владелец заменяет тестовые записи своими работами без изменения отображающих модулей. Бизнес-логика вынесена в composable-функции в папке app/composable.

**Blocked by:** 02 — Русская и английская языковые версии.

**Status:** ready-for-agent

- [x] Подготовлены два тестовых проекта с технологиями, обложками и полноценными русскими и английскими текстами. Поддерживаются категории Fullstack, Frontend и учебные/личные; пустые категории допустимы (уточнение владельца от 23.10.2026).
- [x] Тестовый характер явно указан в названии и описании каждого проекта на обоих языках, без отдельной плашки «Демонстрационный проект». Вымышленные заказчики и результаты не выданы за профессиональные достижения автора.
- [x] Каталог на каждом явном языковом адресе показывает карточки с названием, кратким описанием, обложкой и технологиями. Фильтры работают без перезагрузки, состояние понятно, пустой результат сопровождается сообщением.
- [x] Подробная страница показывает название, описание, контекст и стек; необязательные результаты, период и внешняя ссылка отображаются при наличии. Есть возврат в каталог.
- [x] Карточки, подробности и возможные подборки на главной используют одну запись проекта. Новая подборка на главной не обязательна; если она есть, реальные проекты референса не остаются в ней вместо тестовых.
- [x] Стабильный идентификатор проекта общий для двух языков. Переключение сохраняет проект и смысл выбранной категории каталога; прямой вход и перезагрузка вложенного адреса работают.
- [x] В сгенерированном HTML содержатся тексты и ссылки всех публикуемых проектов. Отсутствующий проект даёт HTTP 404, а не главную с HTTP 200.
- [x] Каталог и подробности выполнены на Tailwind CSS, адаптивны и доступны с клавиатуры; состояния элементов и фокус читаемы.
- [x] Контрольная замена записи с пересборкой меняет карточку, подробности и список генерируемых страниц без изменения разметки. Необязательная внешняя ссылка отсутствует, если назначения нет.
- [x] Проверки через публичные страницы охватывают фильтры, пустой результат, переходы, смену языка, общий контент, прямые адреса, HTTP 404 и обновление записи.

## Scope notes

Использовать согласованные термины «проект портфолио» и «тестовый проект». Данные в файлах, без CMS и базы данных. Подготовка настоящих коммерческих кейсов не входит в задачу; окончательное оформление поисковых метаданных выполняется в 05.

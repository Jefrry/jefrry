# Локальная разработка

Главная с русской и английской языковыми версиями реализована на Vue 3 и Nuxt со строгим TypeScript и Tailwind CSS. Сайт генерируется в статические файлы и не требует базы данных или сервера приложения.

## Требования и запуск

Нужны Node.js 22.12 или новее и pnpm 12.6.0 (версия закреплена в `package.json`).

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Адрес разработки: `http://127.0.0.1:3000`.

## Проверка типов и статическая сборка

```sh
pnpm typecheck
pnpm generate
```

Результат сборки находится в `.output/public/`: готовый HTML `/`, `/ru/` и `/en/`, каталогов `/ru/projects/` и `/en/projects/`, всех проектов на обоих языках, страница `404.html`, изображения, русский PDF, шрифты Manrope и клиентские ресурсы. Для размещения достаточно этой папки. Исходная папка `portfolio-v2-stars/` нужна только как референс при разработке; сборка и готовый сайт её не используют.

На статическом хостинге неизвестный адрес должен выдавать `404.html` со статусом HTTP 404. Не включайте перенаправление всех неизвестных адресов на `index.html` или `200.html`: оно скроет ошибки адресов. Caddy и Docker будут добавлены отдельным пунктом 06. Собственного сервера предварительного просмотра в проекте нет: для разработки используется `pnpm dev`, для размещения — раздача готовых статических файлов.

Автоматические тесты и тестовые зависимости не добавляются по решению владельца. Доступные технические проверки — линтер, TypeScript и статическая сборка.

## Форматирование шаблонов

Между соседними HTML-элементами и компонентами Vue-шаблона обязательна пустая строка. Правило `vue/padding-line-between-tags` настроено в `eslint.config.mjs`; его нарушение считается ошибкой линтера.

```sh
pnpm lint
pnpm lint:fix
```

Первая команда проверяет исходники, вторая автоматически исправляет форматирование. Генерируемые файлы и исходный референс исключены из проверки.

## Обновление содержимого

- `app/constants/profile.ts` — имя, специализация, местоположение, представление, навыки, контакты и отдельное назначение PDF для каждой версии (`PROFILES.ru.resume` и `PROFILES.en.resume`).
- `app/constants/experiences.ts` — периоды, компании, роли, описания, результаты и полный стек опыта. Английские переводы привязаны к компании; общий стек и роли берутся из русских данных. Дата NDA сохранена из референса как «Апрель 2026».
- `app/constants/translations.ts` — тексты интерфейса, подписи управления, заголовки и описания обеих языковых версий.
- `app/constants/projects.ts` — единые записи проектов портфолио: стабильный `id`, категория (`fullstack`, `frontend`, `personal`), технологии, путь обложки и содержимое `content.ru`/`content.en`. Карточка, подробности и список генерируемых адресов используют эту запись. Чтобы добавить или заменить проект, редактируйте данные и пересоберите сайт; разметку и конфигурацию адресов менять не нужно. Для обоих языков сохраняйте один `id` из латинских букв, цифр и дефисов, уникальный в списке.
- `app/constants/projectTranslations.ts` — подписи каталога и подробностей на двух языках. `public/assets/projects/` — обложки, заданные полем `cover`.
- `app/types/` — типы содержимого и параметров компонентов.
- `app/composable/` — бизнес-логика и состояние: `useProjectCatalog` управляет фильтрами категорий и карточками; `usePortfolioProject` выбирает локализованные подробности и проверяет адрес проекта; `useLanguage` определяет язык и адреса навигации; `useSite` применяет язык браузера и общие метаданные; `useErrorPage` готовит содержимое страницы ошибки. Папка подключена к автоимпортам Nuxt через `imports.dirs`. Страницы и компоненты получают готовые данные и действия из composable-функций.
- `app/components/Header.vue` и `app/components/Footer.vue` — общие компоненты, подключённые в `app/layouts/default.vue`.
- `app/components/home/` — секции и общая главная `HomePage.vue`, используемая корневым и языковыми маршрутами.
- `public/assets/egor-ilin-resume.pdf` — исходный русский документ. Обе версии пока ссылаются на него с явной подписью языка. Для английского документа добавьте новый файл и измените только `PROFILES.en.resume.href` и `label`; для русского — `PROFILE.resume`.
- `public/assets/whale.png` и `public/assets/stars.svg` — изображения референса.
- `app/assets/css/main.css` — палитра, шрифтовая тема, звёздный фон и анимация кита. Основное оформление и адаптивность заданы классами Tailwind в шаблоне главной.

После изменения содержимого или материалов снова выполните `pnpm generate`. В раскрывающихся блоках опыта используется стандартный HTML `details`: результаты доступны без JavaScript, блоки управляются клавиатурой. Движение кита отключается системной настройкой уменьшения движения.

## Языковые адреса

`/ru/` и `/en/` задают язык независимо от языка браузера. Переключатель открывает соответствующий адрес другого языка, сохраняя путь, параметры и якорь. Общая функция `app/utils/language.ts` используется также для каталогов и страниц `/ru/projects/<id>/` и `/en/projects/<id>/`.

Исходный HTML `/` русский. После подключения приложения основной язык браузера (`navigator.language`) выбирает русский для `ru` и региональных вариантов вроде `ru-RU`; для английского и неподдерживаемых языков выбирается английский. Выбор выполняется после гидратации, без скрытия содержимого и перенаправлений. На `/` кнопки RU/EN меняют содержимое, язык документа и метаданные на месте, включая адрес с якорем. Обычные обновления не сбрасывают ручной выбор. После перезагрузки снова используется язык браузера; cookies и localStorage для языка не используются.

Неизвестные языковые префиксы не проходят проверку маршрута Nuxt и не генерируются. При размещении статической сборки HTTP 404 для них обеспечивает хостинг по правилу выше. Корневая страница остаётся индексируемой; canonical, языковые альтернативы и sitemap относятся к пункту 05.

Каталог фильтруется без перезагрузки по категории. Параметр `category` сохраняется в адресе, при смене языка и при возврате из подробностей. Сброс восстанавливает все записи. Необязательные `results` и `period` задаются внутри языкового содержимого, `externalUrl` — в общей записи; если поле не заполнено, соответствующий блок не выводится. Два текущих тестовых проекта не имеют внешних назначений, поэтому выдуманные ссылки не показываются.

Кнопки категорий временно закомментированы в шаблоне каталога по решению владельца. Логика категорий в `useProjectCatalog` сохранена: параметр `category` в адресе продолжает работать, доступен сброс пустого результата. Чтобы вернуть кнопки, снимите комментарий с блока в `app/pages/[language]/projects/index.vue`. Поиск полностью удалён: поля ввода, поискового состояния и фильтрации по `q` нет.

В навигации доступны разделы главной и каталог. Заготовки статей относятся к пункту 04.

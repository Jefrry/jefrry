# Локальная разработка

Русская главная реализована на Vue 3 и Nuxt со строгим TypeScript и Tailwind CSS. Сайт генерируется в статические файлы и не требует базы данных или сервера приложения.

## Требования и запуск

Нужны Node.js 22.12 или новее и pnpm 12.6.0 (версия закреплена в `package.json`).

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Адрес разработки: `http://127.0.0.1:3000`.

## Проверка типов и статическая сборка

```sh
pnpm typecheck
pnpm generate
```

Результат сборки находится в `.output/public/`: HTML главной, страница `404.html`, изображения, русский PDF, шрифты Manrope и клиентские ресурсы. Для размещения достаточно этой папки. Исходная папка `portfolio-v2-stars/` нужна только как референс при разработке; сборка и готовый сайт её не используют.

На статическом хостинге неизвестный адрес должен выдавать `404.html` со статусом HTTP 404. Не включайте перенаправление всех неизвестных адресов на `index.html` или `200.html`: оно скроет ошибки адресов. Caddy и Docker будут добавлены отдельным пунктом 06. Собственного сервера предварительного просмотра в проекте нет: для разработки используется `pnpm dev`, для размещения — раздача готовых статических файлов.

Автоматические тесты и тестовые зависимости не добавляются по решению владельца. Доступные технические проверки — линтер, TypeScript и статическая сборка.

## Форматирование шаблонов

Между соседними HTML-элементами и компонентами Vue-шаблона обязательна пустая строка. Правило `vue/padding-line-between-tags` настроено в `eslint.config.mjs`; его нарушение считается ошибкой линтера.

```sh
pnpm lint
pnpm lint:fix
```

Первая команда проверяет исходники, вторая автоматически исправляет форматирование. Генерируемые файлы и исходный референс исключены из проверки.

## Обновление содержимого

- `app/constants/profile.ts` — имя, специализация, местоположение, представление, навыки, контакты и назначение русского PDF.
- `app/constants/experiences.ts` — периоды, компании, роли, описания, результаты и полный стек опыта. Дата NDA сохранена из референса как «Апрель 2026».
- `app/types/` — типы содержимого и параметров компонентов.
- `app/components/Header.vue` и `app/components/Footer.vue` — общие компоненты, подключённые в `app/layouts/default.vue`.
- `app/components/home/` — компоненты главной; `app/pages/index.vue` собирает её из секций.
- `public/assets/egor-ilin-resume.pdf` — исходный русский документ. Замените файл либо укажите новый публичный адрес в `PROFILE.resume.href`.
- `public/assets/whale.png` и `public/assets/stars.svg` — изображения референса.
- `app/assets/css/main.css` — палитра, шрифтовая тема, звёздный фон и анимация кита. Основное оформление и адаптивность заданы классами Tailwind в шаблоне главной.

После изменения содержимого или материалов снова выполните `pnpm generate`. В раскрывающихся блоках опыта используется стандартный HTML `details`: результаты доступны без JavaScript, блоки управляются клавиатурой. Движение кита отключается системной настройкой уменьшения движения.

Пока опубликована только русская главная `/`. Языковые версии относятся к пункту 02, каталог проектов — к 03, заготовки статей — к 04. В навигации показываются только существующие разделы главной.

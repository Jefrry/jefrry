# Языковые адреса и индексируемая корневая страница

Для сайта jefrry.dev выбраны явные русские и английские адреса `/ru/` и `/en/`, чтобы каждая языковая версия имела постоянный адрес для поиска и прямых ссылок. На этих адресах язык браузера не переопределяет язык страницы, а переключатель открывает соответствующую страницу другого языка.

Корневая `/` остаётся отдельным индексируемым входом: язык определяется по языку браузера, ручное переключение не меняет URL. Предложение исключить `/` из индексации владелец явно отклонил. Для неподдерживаемых языков используется английский.

Это сознательное сочетание стабильных языковых адресов и адаптивного корневого входа. При статической генерации браузерный язык недоступен на этапе сборки; спецификация должна определить исходный HTML и правила метаданных, сохраняя индексируемость `/` и отсутствие перенаправления при выборе языка.

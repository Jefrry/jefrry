# Доменная документация

Проект использует единый контекст.

Перед работой читать GLOSSARY.md и относящиеся к задаче
решения из docs/adr/.

Использовать термины словаря. Противоречия с ADR явно
отмечать, не переопределять решения молча.

Если документы отсутствуют, продолжать работу.
Создавать их по мере появления согласованных терминов и решений.

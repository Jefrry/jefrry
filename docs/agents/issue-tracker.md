# Трекер: локальные Markdown-файлы

- Каждая функциональность хранится в `.scratch/<feature-slug>/`.
- Спецификация — `spec.md` внутри этой папки.
- Каждый тикет — отдельный файл `issues/<NN>-<slug>.md`.
- Статус указывается строкой `Status:` в начале документа.
- Зависимости тикета указываются строкой `Blocked by: NN, NN`.
- Комментарии добавляются в конец под заголовком `## Comments`.
- «Опубликовать в трекере» означает сохранить локальный файл.
- Значения статусов определены в `triage-labels.md`.
